# projeto1_arena_tech.c
O projeto Arena Tech foi desenvolvido em linguagem C com o objetivo de analisar a viabilidade de uma maratona gamer.
O programa recebe informações sobre participantes, equipes, computadores, consumo de energia, alimentação, outros custos e orçamento disponível.

A partir desses dados, o programa calcula a quantidade de times, o consumo de energia, os custos do evento, o custo por participante e o saldo do orçamento. Também utiliza estruturas condicionais para verificar a infraestrutura, classificar o consumo de energia, analisar o orçamento e apresentar uma decisão final sobre a realização do evento.

## Uso de Inteligência Artificial

Foi utilizada Inteligência Artificial (ChatGPT) como apoio durante o desenvolvimento do projeto.

A IA foi utilizada principalmente para auxiliar na compreensão do problema, na revisão da lógica, na identificação de possíveis erros e na compreensão de conceitos de programação em C, como estruturas condicionais, operadores lógicos, divisão real e utilização da função ceil().

O código foi revisado, testado e compreendido pelos integrantes do grupo, que realizaram as alterações necessárias e verificaram os resultados obtidos pelo programa.

## Testes

O programa foi compilado e testado com diferentes conjuntos de dados, verificando situações de infraestrutura suficiente e insuficiente, diferentes níveis de consumo de energia, diferentes situações de orçamento e diferentes decisões finais.

O teste mínimo obrigatório também foi realizado conforme os dados fornecidos no enunciado.
